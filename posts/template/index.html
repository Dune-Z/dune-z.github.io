Writing Paper-Style Posts on This Site

Yifei Zuo1
1Northwestern University

This page is both a living demo and the starter template for blog posts. It mimics the typography of my papers: the title, authors, section headings, and bold text are set in Latin Modern Sans, while body text keeps the site's serif stack. Sections and figures number themselves, links glide with the same animated highlighter as the homepage, and figures can be revealed on scroll or made fully interactive. To start a new post, copy posts/template/ to posts/<your-slug>/ and replace the content.

Typography

Body text stays in the site's serif stack, and anything bold switches to Latin Modern Sans, exactly like \textbf in the paper class. Run-in paragraph headings work the same way:

Links. Every link flavor rides the shared spring-animated highlighter: black site links, blue reference links like the citations in the paper, arXiv-red links, and Northwestern purple. Organization names can reuse the homepage's monospace style with class="custom-link mono-link", e.g. Tilde Research.

Math. MathJax is loaded on every page, so inline math such as \( \hat{f}(q) = \sum_i w_i(q)\, v_i \) and display math both work: $$ w_i(q) \propto \exp\!\left( -\frac{(x_i - q)^2}{2h^2} \right). $$

Section numbering

<h2> and <h3> inside a post are numbered automatically with CSS counters (this one is 1.1). Add class="no-number" for unnumbered headings such as Acknowledgements.

Figures

Wrap figures in <figure class="post-figure"> with a <figcaption>; the sans-bold "Figure N:" label is added automatically. Give any element data-animate="fade-up" (or "fade", "zoom") to reveal it as it scrolls into view; data-animate-delay="150" staggers the entrance. Users who prefer reduced motion see everything immediately.

Interactive figures

For interactive figures, put an inline SVG (or canvas) inside the figure and drive it with a small <script type="module"> at the end of the post. The demo below plots the kernel weights \( w_i(q) \propto \exp(-(x_i - q)^2 / 2h^2) \): move your pointer across the plot to slide the query \( q \), and drag the slider to change the bandwidth \( h \).

Starting a New Post

  1. Copy posts/template/ to posts/<your-slug>/.
  2. Update the <title>, the header card (title, authors, abstract), and the Date / Code rows.
  3. Write sections with <h2>/<h3>; numbering is automatic.
  4. Add figures as post-figure blocks; sprinkle data-animate for scroll reveals.
  5. Keep per-post interactivity in a <script type="module"> at the bottom of <main>.
